# -TARHAL-USING-BASIC-PYTHON-WITH-STREAMLIT-AND-CSS
A Python and Streamlit travel planning application that helps users choose a destination and get recommendations based on budget, travel type, and place type.

Trahel is a travel recommendation website built using Python, CSS, and Streamlit.
The website starts with a login or register page. After logging in, the user can go to the Explore page to discover Saudi cities and learn more about them, such as information about the city and famous places.
The user can then choose:
The destination
The budget
Who they are traveling with
Trahel currently has four cities:
Riyadh
Jeddah
AlUla
Abha
Based on the user’s choices, the website shows recommendations such as:
Entertainment
Tourist destinations
Restaurants
Cafes
Python Concepts Used
Dictionaries
We used dictionaries to organize the cities. Inside each city, we have the budget, who the user is traveling with, and the recommendations such as tourist destinations, restaurants, cafes, and entertainment.
For Loop
We used a for loop to go through the dictionary and check the user’s choices. Then, it shows the recommendations that match the user’s choices.
If Statements
We used if statements to check the user’s choices and move them to the right page or show the suitable results.
Classes
We used classes to organize some of the information and user preferences in the project.
Technologies Used
Python
Streamlit
CSS
How to Run
First, install Streamlit:
pip install streamlit
Then run the app using:
streamlit run app.py
