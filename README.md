# -TARHAL-USING-BASIC-PYTHON-WITH-STREAMLIT-AND-CSS
A Python and Streamlit travel planning application that helps users choose a destination and get recommendations based on budget, travel type, and place type.

## About the Project

**Trahel** is a travel recommendation website developed using **Python, Streamlit, and CSS**. The website helps users explore Saudi cities and discover recommended places based on their destination, budget, and travel preferences.

The website starts with a **Login or Register** page. After logging in, users can access the **Explore** page to learn more about Saudi cities, including general information and famous places.

Users can then start planning their trip by selecting:

* Destination
* Budget
* Travel group

Based on the user's selections, Trahel provides recommendations in the following categories:

* Entertainment
* Tourist Destinations
* Restaurants
* Cafes

## Available Cities

Trahel currently includes the following Saudi cities:

* Riyadh
* Jeddah
* AlUla
* Abha

## How It Works

The application follows these main steps:

1. The user logs in or creates an account.
2. The user explores the available Saudi cities.
3. The user selects a destination.
4. The user selects a budget.
5. The user selects who they are traveling with.
6. The system processes the user's choices.
7. The website displays recommendations that match the selected preferences.

## Installation and Usage

### 1. Install Streamlit

Open the terminal and run:

```bash
pip install streamlit
```

### 2. Clone the Repository

```bash
git clone <YOUR-GITHUB-REPOSITORY-LINK>
```

### 3. Navigate to the Project Directory

```bash
cd Trahel
```

### 4. Run the Application

```bash
streamlit run app.py
```

After running the command, the application will open in the web browser.
